# Working on this repository

Static one page site. Plain HTML and CSS, no framework, no build, no JavaScript. Keep it that way unless asked.

## Rules

- Do not add analytics, cookie banners, chat widgets, newsletter forms, calendar embeds, or pricing.
- Do not add images, icons, gradients, shadows, or rounded cards. The design is type and hairlines only.
- Ink `#16232E` is the only brand colour. Add a colour only if asked.
- Copy: British English, short sentences, no em dashes, no marketing language, nothing invented. Unconfirmed facts stay as bracketed placeholders.
- Design tokens live in `:root` in `styles.css`. Change values there, not inline.
- Keep the section structure: opening statement, what Penvar does, who it is for, about Craig Mills, contact, footer.
- Check narrow widths after any layout change. Sections collapse to one column under 760px.

## Outstanding
